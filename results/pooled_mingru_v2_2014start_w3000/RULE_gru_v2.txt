           momentum=0.95 max_grad_norm=1.0 anneal=1 min_lr_ratio=0 mask=1 xstd=0 link=softplus loss=qlike es=qlike lin=1
           dec_zero=1 wd=0 wd_enc=0 lr_lin=0 wd_lin=0 lin_init=data/pmf_lin_init/<set>/tune_f3_L{L}_wl0.003.f32
         (patience = max_epochs: early stopping never fires). E1 = 300 unless G2 sets 1,000 for the set.
         Metrics: TQ_0 = the training QLIKE of the frozen shortcut alone (epoch 0: decoder zero), computed offline on the
         training rows [w0 + L - 1, 47,202) with the trainer's loss formula (r = max(y^2, eps^2) / (f^2 + eps^2), eps 1e-3,
         f = softplus(c + s v.x), c = log(expm1(mu_y)), s = sd_y (1 + exp(-c)), mu_y / sd_y the float32 training-target mean /
         sd); TQ_e = the row-weighted epoch-e mean of steps.csv's minibatch loss (the epoch_curves_remote.py reduction);
         rho(e) = TQ_e / TQ_0. Also logged: epochs to rho <= 0.9 / 0.5 / 0.1, capped-gradient and non-finite counts, grad norm
         (mean / max an epoch), validation QLIKE an epoch and the train-validation gap (diagnostics).
         A cell (H, L) at learning rate lr MEMORIZES if rho(E1) <= 0.5 for each of the 3 seeds (rho <= 0.1 reported).
         lr of a cell = argmin over the lr set of the 3-seed mean TQ_E1 (training only; ties: the lower lr).
         Grid: core H {16, 64, 256} x L {8, 20, 48}; then
           + H 1,024 x L {8, 20} only if no core cell memorizes;
           + L 115 x H {64, 256} only if the cheapest memorizing cell (after the core, and after H 1,024 if run) is at L 48.
         Pick (H*, L*, lr*) = the cheapest memorizing cell over every cell run, by walk cost an epoch (the old run's measured
         P100-s a tune model-epoch, analysis_w3000/summary.json epoch_cost; HAR: (16,8) .0194 (16,20) .0238 (64,8) .0264
         (64,20) .0401 (256,8) .146 (16,48) .206 (256,20) .250 (64,48) .268 (16,115) .293 (64,115) .404 (256,48) .608
         (256,115) 1.227 (1024,20) 5.53; full: (16,8) .0373 (64,8) .0475 (16,20) .0495 (64,20) .0707 (256,8) .200 (16,48) .242
         (256,20) .330 (64,48) .346 (256,48) .607; a cell missing from the table: its Stage-1 measured P100-s a model-epoch),
         ties to the smaller H, then the smaller L. If no cell memorizes: the cell with the lowest 3-seed mean rho(E1) at its
         lr, labelled "capacity-limited". No affordability cap.
         Concurrency (measured safe limits): CONC 24 for H <= 64 and L <= 20; 7 for H 1,024; otherwise 12 on HAR, 6 on the full
         set (full H 256 L 48 ran out of GPU memory at 24).

STAGE 2  Regularize and validate. Frozen from Stage 1: H*, L*, lr*. Shortcut lin=1 dec_zero=1 lr_lin=0 wd_lin=0 at the fold's
         own wd_lin 0.003 ridge. Mode refit (the walk's exact procedure), fully annealed, no early stopping:
           mode=refit w0=fit0 w1=fit1 fc_n=3575 epochs=E max_epochs=E patience=E (other keys as Stage 1, no val_tail /
           embargo / es), lin_init = the fold's ridge init: window mask on [fit0, fit1), Gram on [fit0 + L* - 1, fit1),
           wl 0.003 (data/pmf_lin_init/<set>/s2_f<k>_L<L>_wl0.003.f32).
         Forecast rows [fit1, fit1 + 3,575); scored rows [fit1 + 325, fit1 + 3,575) = the fold's validation block.
         Axes: tau (total decoupled decay) {0, 0.3, 1, 3}: wd = tau / (0.5 lr* S (E + 1)), S = ceil((fit1 - fit0 - L* + 1) / 128)
               the fold's steps an epoch (sum of the cosine factors over E epochs = 0.5 (E + 1)), so exp(-tau) is the total
               shrink of the decayed weights over the run;
               wd_enc {0, 3, 15} on the full set only (0 on HAR: its pf is 0.01 on every column);
               E {10, 20, 40, 80, 160, 300} (if G2 set Stage 1 to 1,000 epochs for the set: + {600, 1,000}).
         Ladders for extensions: tau low edge 0 -> 0.1, then 0.03; high edge 3 -> 9, then 27. wd_enc high edge 15 -> 75, then
         375 (0 is a natural bound, not extended). E ladder 5, 10, 20, 40, 80, 160, 300, 600, 1,000, 2,000 (next value beyond
         the edge). At most 2 extensions per axis.
         Criterion C (a configuration, a seed set): for each fold, the QLIKE of the seed-mean forecast fbar over the fold's
         validation rows with y > 0 (q = y^2 / fbar^2, mean of q - log q - 1); C = the equal-weight mean over folds 1-3.
         A configuration without finite positive forecasts of every seed on every validation row of every fold is skipped.
         Rule: (1) top 5 by C on the screen seeds; (2) the shortlist rerun with the 5 fresh seeds; (3) the pick = argmin C on
         the fresh seeds only; (4) ties within 1e-7: the lower walk cost (fewer epochs E), then the configuration name order;
         (5) a pick at an edge of the current grid on tau, wd_enc or E: the next ladder value of every such axis is added (the
         full factorial of the extended grid not yet run, screen seeds) and (1)-(3) are redone over every configuration run;
         repeat until the pick is interior or every edge axis has had its 2 extensions (or is at a natural bound).
         No SE gating. Reported, not deciding: the paired 10-day (130-row) moving-block bootstrap stratified by fold (blocks
         drawn within each fold, B 2,000, seed 20261023) SE of C(config) - C(pick) over the shortlist on the fresh seeds; the
         seed jackknife SE of C (leave one fresh seed out); the 90% Hansen model confidence set (T_max, the same bootstrap)
         over the shortlist.
EPOCHS   Refit epochs in the walk: E* (the same for every seed; no per-seed early-stop epochs). wd of the walk: the pick's tau
         with S of the walk window (39,000 rows).
