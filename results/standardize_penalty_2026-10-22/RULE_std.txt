STANDARDIZE_PENALTY (module flag of experiments/pool_linear_pretune.py, default True; False = the runner before the
flag, bit for bit).  The pooled intraday ridge, lasso and elastic net are fit as if every predictor column were scaled
to unit variance within its training window (glmnet standardize=TRUE), implemented as per-column penalty weights.

1. The code's penalty, exactly (the spec's units, specs/causal_tune_linear.py + the runner's penalty factors pf):
   theta = the coefficient vector on the augmented design [X, 1]; the intercept column is locked (unpenalized, pf
   unused); pf_j = r on the HAR benchmark block (har_ma_* and calendar), 1 elsewhere (r = 0.01 all_features, 1 baseline).
   n = rows of the fit, a = the penalty (alpha), l1 = l1_ratio (lasso 1, elastic net 0.5).
     ridge (sklearn Ridge units):     min ||y - X theta||^2 + a sum_j pf_j theta_j^2
                                      i.e. (X'X + diag(a pf_j)) theta = X'y
     lasso / elastic net (sklearn ElasticNet units):
                                      min (1/2n) ||y - X theta||^2 + a sum_j pf_j [ l1 |theta_j| + (1-l1)/2 theta_j^2 ]
                                      i.e. Gram form mu_j = n a l1 pf_j (L1), lam2_j = n a (1-l1) pf_j (on Gr's diagonal)
   With the flag on, s_j = the column's s.d. in the fit's rows, and the penalty on the standardized coefficient
   gamma_j = s_j theta_j of z_j = x_j / s_j is the existing one, so in the original units:
     ridge:          a sum_j pf_j s_j^2 theta_j^2                 (diagonal a pf_j s_j^2)
     lasso / enet:   a sum_j pf_j [ l1 s_j |theta_j| + (1-l1)/2 s_j^2 theta_j^2 ]
                                                                  (mu_j = n a l1 pf_j s_j, lam2_j = n a (1-l1) pf_j s_j^2)
   i.e. L1 weight pf_j s_j, L2 weight pf_j s_j^2.  Back-transform: theta_j = gamma_j / s_j.

2. s_j = np.std(x_j, ddof=0) over exactly the rows the fit uses (after the identifiability mask; masked columns are 0
   there), so causal: only rows inside the fit's window.  Intercept / centering unchanged: the free, unpenalized
   intercept absorbs any column shift, so the fit equals the centred-and-scaled glmnet fit; nothing is centred.
   Columns already masked stay masked.  A non-locked column with s_j < 1e-12 in the fit's rows is masked for that fit
   (theta_j = 0).  In the lasso / enet walk (weights held between seeds) such a column joins the walk's mask until the
   next tune boundary, as the spec's between-tune mask additions; in the ridge walk (weights every bar) it is left out
   of that bar's solve only.

3. Update cadence.
   ridge: weights from each fit's own window, every bar (the walk refits every bar).  At every cold seed s = np.std of
     the masked window; between seeds s comes from the window's column sums and sums of squares about the seed-time
     column means, updated with the entering and leaving rows (equal to np.std of the current window up to rounding,
     and dependent only on the state since the block's seed, so the chunk seam stays exact); a column that is exactly
     constant over the current window (the spec's run-length tracker on raw rows, columns only) has s_j = 0.  The
     solve every bar: (X'X + diag(a pf_j s_j^2)) theta = X'y on the kept columns, X'X and X'y kept rank-one since the
     seed (replaces the Sherman-Morrison update of the fixed-penalty inverse).
   lasso / elastic net (online homotopy): weights recomputed at every cold seed -- the 250-solve tune boundary, the
     spec's between-tune mask-addition reseeds and the KKT-triggered reseeds (WALK_KKT_RESEED) -- from the seed's
     window, and HELD FIXED between seeds (the warm state's mu_vec and the L2 term on Gr's diagonal are the seed's).
     Approximation: between seeds the warm path solves the current window's problem with the last seed's weights, not
     the current window's; the KKT check certifies that held-weight problem.  Measured and reported: the number of
     cold-seed weight updates, the max relative change of a weight between consecutive seeds, and the forecast effect
     at block ends (warm held-weight forecast vs the batch fit with the current window's weights) on the check chunks.

4. Pretune: the same weights computed on each fold's fit block (the 13,000 rows before the embargo); validation rows
   never enter s.  (In-walk causal re-choice, --sched causal, not used by the 13-bar runs: the grid fits use s of the
   forward split's fit block, the seed s of the whole window.)

5. Penalty grid rule (decided now, on the pre-2012 criterion only -- the mean validation MSE of the 4 pre-sample folds):
   if a model's selected penalty is at either end of its grid, extend the grid by factors of 10 in that direction
   (one decade per round, the pretune run for the new value only) until the selection is interior; every extension
   reported.  Applies with the flag on (the new specification); with the flag off the selection is as before (so the
   flag-off rerun reproduces the frozen penalties).  Termination safeguards (my addition, flagged for the owner): stop
   when the new end's criterion is within 1e-6 relative of the previous end's (the penalty no longer binds at that
   end: the argmin is taken and reported as "flat"), or after 6 extensions in one direction (reported, owner's call).

6. Scope: the pooled intraday linear pipeline only (experiments/pool_linear_pretune.py modes pretune and walk, and the
   orchestrator experiments/pooled_linear_rerun_2026_10_19_13.py that runs it).  The flag lives in the runner, which no
   closing-interval path imports (src/unification.py RollingTunedLinear, experiments/close_exogpen*.py,
   close_linear_pretune.py): they keep their behaviour.  src/models/reclasso_har.py unchanged.  Trees, MinGRU and the
   OLS (unpenalized; --est ols) unaffected.

EVIDENCE MASK (under STANDARDIZE_PENALTY only; flag off bit-identical):
  * a non-locked column enters a standardized fit only if at least STD_MIN_EVIDENCE = 250 (= MODE_MIN_PRINTS, by name,
    asserted equal) rows of the fit's window differ from the column's modal value in that window (evidence_j = n -
    count of the modal value; values compared exactly, on the masked design).  Below: masked exactly like the
    identifiability mask (zeroed in the fit, coefficient 0).  The s < 1e-12 rule stays (implied by it for n > 250).
  * ridge: evaluated at every bar with its per-bar weights; the bar's solve leaves the column out (the same fit as the
    column zeroed).  Implementation: the exact mode at every cold seed, then per bar the count of window rows that
    differ from the seed-time modal value, updated with the entering and leaving rows.  Exact within a block: with
    block length B <= 250 and window n > 2 (250 + B), a value holding more than n - 250 rows at a bar held at least
    n - 500 at the seed, so it was the seed-time mode (two values cannot both hold n - 500 rows); hence "evidence < 250"
    is the same event for the tracked count and the true count (asserted n > 1000).
  * lasso / elastic net: evaluated at every cold seed (exact mode of the seed's window; a column masked by this rule
    only is un-masked at a later seed when its evidence is back to >= 250 -- un-masking is a seed-time event, the
    identifiability mask itself is still only recomputed at the tune boundary), plus a between-seed tracker (the count
    above, per bar): when a live column's count drops below 250 it is added to the mask and the walk takes a cold reseed
    (which also refreshes the weights and the seed-time modes).
  * pretune: the same rule on each fold's fit block (exact mode); in-walk causal re-choice: on the forward split's fit
    block.  The --std-check-blockends refit applies it to the current window.
  * recorded: per seed the number of columns the evidence mask removes (beyond the identifiability mask) and which;
    the evidence-triggered reseeds.

ADDENDUM 2 -- written 2026-10-22T18:02-07:00, before any code change or run of this rule.  Owner:
"the proper rule" -- evidence is counted on the variable itself, not on the smoothed average (a k-bar average repeats
each event k times, so its own off-mode row count overstates the evidence).
  * The evidence of column (v, k) -- value average adj_<v>_ma_<k> or availability average <v>_avail_ma_<k> -- is the
    number of rows of the fit's window in which v's own k = 1 column OF THE SAME KIND (adj_<v>_ma_1, resp.
    <v>_avail_ma_1) differs from that k = 1 column's window mode (exact equality, on the masked design).  (v, k) enters
    a standardized fit only if that count is >= STD_MIN_EVIDENCE = 250; otherwise it is masked like the
    identifiability mask (coefficient 0).  If v's k = 1 column is itself masked (its masked-design column is 0: count 0)
    or absent from the design, every horizon of v follows it (masked).
  * HAR and calendar columns (the backbone, penalty factor r) and the locked intercept are exempt from the evidence
    rule; the s < 1e-12 rule still applies to every non-locked column.  A non-backbone column of neither form keeps its
    own count (none expected; counted and reported).
  * Cadence and mechanics unchanged from addendum 1: ridge per bar (seed-time modes + per-bar off-mode counts of the
    k = 1 columns), lasso / elastic net at every cold seed plus the between-seed tracker on the k = 1 counts (a drop
    below 250 masks every live column of that group and reseeds cold), pretune on each fold's fit block.

  Under STANDARDIZE_PENALTY only (flag off bit-identical).
  * With a free, unpenalized intercept, shifting a column by a constant leaves the slopes and the forecasts unchanged
    exactly, so centring is implemented as fixed offsets: at every cold seed m_j = the seed window's mean of column j
    (masked design; 0 on masked columns; the intercept column stays 1), the state is built on x - m (Gram, X'y, batch

    offsets are held between seeds like the weights, and the forecast is (x - m)' theta_c (theta_c's intercept = the
    original intercept + m' beta).  Lasso / elastic net: the warm homotopy and the KKT check run on the centred
    state.  Ridge: the same offsets (seed-time means, re-anchored at every seed), the per-bar solve on the centred
    augmented system.  The batch fits (pretune folds, the causal re-choice grid, the block-end refit, the cold seed)
    already residualize every column on the intercept (FWL: the window-centred columns) for the lasso / enet; ridge
    pretune / grid fits: solved on the fold's fit-block-centred columns.

DISTINCT-EVIDENCE RULE: variable v's columns of a kind (value adj_<v>_ma_<k>, or availability <v>_avail_ma_<k>) enter a
standardized fit only if v's k = 1 column of that kind differs, on at least STD_MIN_EVIDENCE = 250 rows of the fit's
window (exact inequality, masked design), from the k = 1 column of every variable u of the same kind that comes
earlier in design order (the order of the k = 1 columns) and is kept; otherwise all of v's columns of that kind are
masked like the identifiability mask.  "Kept" = passes the evidence rule (>= 250 off-mode rows of its own k = 1
column) and this rule against every earlier kept variable (greedy in design order: of a group of near-copies the first
is kept).  It complements the evidence rule and the exact-duplicate mask (both unchanged).  HAR and calendar exempt.
Evaluation points as the evidence rule: ridge per bar (exact pairwise differing-row counts of the k = 1 columns,
updated with the entering and leaving rows, and the greedy rule re-run on them every bar); lasso / elastic net at every
cold seed (from scratch) plus a between-seed tracker: when a pair of currently live (kept) variables' differing-row
count drops below 250 the later one is masked and the walk reseeds cold; pretune on each fold's fit block.  Recorded:
the variables the rule masks at every seed (and in every pretune fold).

ADDENDUM 3 (the rule in force) -- written 2026-10-22T19:25-07:00, before any code change or run of it.  Owner: "do it" (option
(a): scaled coordinates + the binomial availability rule, as tested in Step 1'; the condition-number comparison with
the flag-off lasso is retired as an acceptance criterion and reported as information only).  Under STANDARDIZE_PENALTY
only (flag off bit-identical).
(1) SCALED COORDINATES -- the same estimator.  The lasso / elastic net solve in z_j = (x_j - m_j) / s_j (m, s = the
    seed window's column mean and s.d., masked design; masked columns 0; intercept column 1), with the uniform penalty
    (penalty factors pf only, no s weights) and the intercept free; m and s are fixed at every cold seed and held
    between seeds (entering / leaving rows transformed with the held m, s: rank-one updates), the warm homotopy and the
    KKT check run in z, coefficients back-transformed beta_j = gamma_j / s_j, beta_0 = gamma_0 - m' beta, the forecast
    z(x)' gamma (identical in exact arithmetic).  This is the weighted + centred problem of addenda 0-2 written in the
    coordinates the solver works in (verified on 27 origins to <= 8.3e-13, Step 1'), so it is the same estimator.
    Ridge: exact per-bar scaling -- every bar's solve is (Z_t'Z_t + diag(a pf)) gamma = Z_t'y with z = (x - m0) / s_t,
    m0 the seed-time means (exact by the free intercept), s_t the bar's own window s.d. (the per-bar weights of
    addendum 0), i.e. the centred Gram divided by s_t s_t', then beta = gamma / s_t.
(2) BINOMIAL AVAILABILITY RULE -- a data-cleaning rule: an availability average over k intervals is a proportion with
    sampling resolution se = sqrt(p (1 - p) / k), p = its window mean, and variation within the column's own sampling
    resolution carries no detectable information.  For the availability averages <v>_avail_ma_<k> with k > 1 that the
    existing masks leave live (identifiability; the evidence rule on the k = 1 column -- both run first): (i)
    near-constant: masked if its window s.d. <= se; (ii) near-duplicate: in design order, masked if, against an earlier
    KEPT availability average of the same k, the window s.d. of the difference <= sqrt(2) se_pair, se_pair =
    sqrt(pbar (1 - pbar) / k), pbar = (p_i + p_j) / 2.  k = 1 flags, value averages, HAR and calendar exempt.  Masked
    like the identifiability mask.  Window moments: exact at every cold seed (and in every batch fit), between seeds
    the column sums and cross-products of the k > 1 availability averages about the seed-time means updated with the
    entering and leaving rows.  Evaluation points as the evidence rule: ridge per bar; lasso / elastic net at every
    cold seed (columns masked by this rule alone re-evaluated there) plus a between-seed tracker that masks and
    cold-reseeds when a live column falls to s.d. <= se or a live pair becomes a near-duplicate; pretune on each fold's
    fit block.
