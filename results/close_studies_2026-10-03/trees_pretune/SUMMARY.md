## CPU estimate for the full-size cluster run (from this run's fit times)

- pre-tune, one model: 4 studies x 2000 trials x 7 folds x 20.5 s (this run's mean fold fit, 284 fits) = 319 fit CPU-hours; a study's wall time ~ 2000 x 32.2 s (mean slowest of the 4 folds of a trial here; 7 folds run longer) = 17.9 h, i.e. 573 allocated slot-hours with 8 slots a study
- walk, one model: refit every 10 = 7 arms x 147 refits x 10.2 s = 2.9 CPU-hours; refit every session = 7 x 1469 x 10.2 s = 29 CPU-hours (upper bounds: arms that share a configuration share fits); retunes: 5 x 15 trials x 2 folds x 2 paths x 20.5 s = 1.7 CPU-hours a walk task
- XGBoost: the same counts at XGBoost's fit time, which this run did not measure at scale; Hoffman2 nodes differ in speed from this machine.
