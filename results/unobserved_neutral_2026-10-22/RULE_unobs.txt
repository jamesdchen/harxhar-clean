PRIMARY RULE (flag UNOBSERVED_NEUTRAL, default True; False = the current design bit for bit):

  UNOBSERVED_NEUTRAL: a scaled value column adj_<c>_ma_<k> is set to the neutral
  value 0 on every row whose k-bar averaging window holds no observed bar of
  series c (its <c>_avail_ma_<k> is 0); otherwise unchanged. Availability
  averages are untouched.

Placement: applied in src/backtest/executor.py after the robust scaling and after the
LATE_START_WARMUP step.

Why it is causal: <c>_avail_ma_<k> at row t is the trailing mean over the k bars of the
48-interval grid ending at t of the availability flag <c>__obs, which is recorded before
any fill from the raw feed at those bars only. Whether it is 0 at t is therefore a
function of data at or before t only, the same information set the existing
adj_<c>_ma_<k> value already uses. Setting a value to the constant 0 adds no
information from after t; and the rule does not feed back into the scaler (the
scaler statistics on [t-W, t) are computed exactly as before, from the unmasked
series), so no later row's value depends on the change either.

Optional secondary variant (OFF by default; only if routine gaps dominate the changes;
clearly labelled, NOT the primary rule): mask only rows where, in addition, series c has
been unobserved for more than FFILL_LIMIT (26) bars running at t (i.e. the fill cap
has expired and the stopped-feed neutral fill is what the average holds).
