# harxhar paper: flat version for Overleaf

`main.tex` is the paper as one file:
* literal numbers;
* no `\input`;
* the tables inlined.

It is generated from the paper's source of record in
[`jamesdchen/harxhar-clean`](https://github.com/jamesdchen/harxhar-clean):
* `writeup/paper_rehaul.tex`;
* the section files in `writeup/rehaul/`;
* the numbers and tables in `writeup/generated/`.

It is generated by `writeup/overleaf_sync/flatten.py` there. Edit it in Overleaf as usual.

Edits come back to the source with `writeup/overleaf_sync/unflatten.py`:
* **Prose.** Applied to the section files, with the replaced lines kept in dated comments.
* **Generated numbers and tables.** Not applied: they are reported as conflicts naming the generator to change.
  They are overwritten here by the next flatten.

Linking: in Overleaf, New Project, then Import from GitHub, then this repository. Pull and push from the project's
GitHub menu. See `writeup/overleaf_sync/README.md` in harxhar-clean for the round trip.
