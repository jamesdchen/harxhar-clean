\subsection{Replication package}
\label{app:rh_repro}
\begin{itemize}
\item \textbf{Contents.} The code that builds the design matrices from the data, fits every model and writes every
  forecast, and the generators that turn the stored forecasts into the numbers, tables and figures of the paper. Its
  README maps each number, table and figure to its generator and inputs.
\item \textbf{Numbers.} The numbers in the text are macros written by these generators
  (\texttt{writeup/\allowbreak make\_*.py}) to files in \texttt{writeup/\allowbreak generated/}; one switch
  (\texttt{REHAUL\_\allowbreak FINAL\_\allowbreak RUN}, \texttt{writeup/\allowbreak final\_run.py}) points them at the
  final forecasts.
\item \textbf{Fits.} The pooled linear models are fitted by
  \texttt{experiments/\allowbreak pooled\_\allowbreak linear\_\allowbreak rerun\_\allowbreak 2026\_10\_19\_13.py} and
  the tree ensembles by \texttt{experiments/\allowbreak pooled\_\allowbreak trees\_\allowbreak rerun\_13.py}, the
  random forest with Intel's oneDAL engine
  (Intel Extension for Scikit-learn).
\item \textbf{Software.} \texttt{requirements.txt} names the packages, with a version range for each; it is not a
  pinned lock file. The package does not record hashes of the design matrices, the CPU class of the fits or their
  compute time.
\end{itemize}
